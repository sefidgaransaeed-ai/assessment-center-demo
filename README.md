# نمونه کانون‌یار

یک نمونه تعاملی تک‌فایلی و بدون وابستگی خارجی برای نمایش جریان کانون ارزیابی.

## اجرای محلی

فایل index.html را در مرورگر باز کنید.

## انتشار با GitHub Pages

محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید و از تنظیمات مخزن، Pages را از شاخه اصلی و پوشه ریشه فعال کنید. پس از انتشار، GitHub نشانی وب صفحه را می‌سازد.

## نکته

این نمونه فقط رابط کاربری و تعامل‌های نمایشی را دارد. اتصال واقعی به ربات تلگرام، پردازش صدا، ذخیره روی هارد یا تولید گزارش متصل نیست. داده‌های نمایش‌داده‌شده ساختگی‌اند.
